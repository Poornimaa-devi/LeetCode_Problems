<h2><a href="https://leetcode.com/problems/generate-parentheses">22. Generate Parentheses</a></h2>

</pre><p><strong class="example">Example 2:</strong></p>
<pre><strong>Input:</strong> n = 1

</pre>
<p>&nbsp;</p>

	<li><code>1 &lt;= n &lt;= 8</code></li>
